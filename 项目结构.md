# 项目结构（demo 精简版）

> 单人本地跑通的版本，**不引入 docker / k8s / 部署脚本 / 复杂配置中心目录**。中间件用本机安装或 `application.yml` 直配即可。配套 `开发文档.md` 一起看。
>
> ORM 用 **原生 MyBatis**（XML + Mapper 接口），**不引入 MyBatis-Plus**。

---

## 1. 顶层结构

```
railway-ticket/
├── pom.xml                       # 父 POM：聚合 + 依赖管理
├── README.md
├── 开发文档.md                   # 详细开发计划
├── 项目结构.md                   # 本文件
│
├── common/                       # 公共模块（单 jar，按包分类）
├── gateway/                      # 网关
├── service-user/                 # 用户
├── service-train-stock/          # 车次+库存
├── service-ticket/               # 票务
├── service-payment/              # 支付
├── service-order/                # 订单（编排）
├── service-search/               # ES 检索
└── service-notification/         # 通知
```

> 没有 `deploy/` `script/` `k8s/` `docs/` `sql/` 集中目录：建表 SQL 放各服务 `resources/db/init.sql`，配置放各服务 `application.yml`。

## 3. 业务服务统一目录模板

```
service-{name}/
├── pom.xml                       # 依赖 common + 所需 api-* + 启动器
└── src/main/
    ├── java/com/railway/{name}/
    │   ├── {Name}Application.java         # @SpringBootApplication
    │   │
    │   ├── controller/                   # REST 接口
    │   │   └── XxxController.java
    │   │
    │   ├── service/                      # 业务层
    │   │   ├── XxxService.java           # 接口
    │   │   └── impl/
    │   │       └── XxxServiceImpl.java   # 实现（事务边界放这里）
    │   │
    │   ├── manager/                      # 跨外部资源协调（可选）
    │   │   └── XxxManager.java           # 如 OrderStockManager
    │   │
    │   ├── mapper/                       # MyBatis Mapper 接口（XML 放 resources/mapper/）
    │   │   └── XxxMapper.java
    │   │
    │   ├── entity/                       # 数据库实体
    │   │   └── XxxDO.java
    │   │
    │   ├── dto/                          # 入参（按用途细分）
    │   │   ├── request/                  # 增删改
    │   │   │   └── XxxReq.java
    │   │   └── query/                    # 列表查询
    │   │       └── XxxQuery.java
    │   │
    │   ├── vo/                           # 出参
    │   │   └── XxxVO.java
    │   │
    │   ├── enums/                        # 本服务私有枚举（公用的放 common/enums）
    │   │   └── XxxStatusEnum.java
    │   │
    │   ├── feign/                        # Feign 调用客户端（**只在调用方放**）
    │   │   ├── XxxFeignClient.java
    │   │   └── XxxFeignFallbackFactory.java
    │   │
    │   ├── consumer/                     # RabbitMQ 消费者
    │   │   └── XxxConsumer.java
    │   │
    │   ├── producer/                     # MQ 发送（可选，业务简单可省）
    │   │   └── XxxSender.java
    │   │
    │   ├── config/                       # 本服务专属配置（如 RabbitAdmin 声明队列）
    │   │   └── XxxConfig.java
    │   │
    │   └── util/                         # 本服务私有工具
    │       └── XxxUtil.java
    │
    └── resources/
        ├── application.yml               # 端口 + 数据源 + Redis + Nacos + MQ
        ├── logback-spring.xml            # MDC: traceId / userId
        ├── db/
        │   └── init.sql                  # 本服务的建表脚本
        ├── mapper/                       # 自定义 XML（可空）
        │   └── XxxMapper.xml
        └── lua/                          # 本服务私有 Lua（可空）
```

> **不引入 `api` 聚合模块**：Feign 接口就放在调用方服务里，例如 `service-order` 调用 `service-train-stock` 时，`StockFeignClient` 直接放在 `service-order/feign/`，DTO 复制一份即可。demo 阶段可以接受这种重复（生产再抽 `api` 模块）。

## 7. 与企业级版本的差异

| 删除项 | 原因 |
|---|---|
| `deploy/docker-compose/` `k8s/` `nginx/` | 本地 demo，docker 太重 |
| `script/` 运维脚本 | 单人用不到 |
| `docs/` 设计文档 | README + 注释够用 |
| `sql/` 集中目录 | 直接放各服务 `resources/db/` |
| `common-*` 拆 7 个 | 单 common 包内分类即可 |
| 改用 MyBatis-Plus | 改回**原生 MyBatis**（XML + Mapper），分页用 PageHelper |
| `api-*` 聚合模块 | Feign 接口放调用方 `feign/` 即可 |
| `bootstrap.yml` + Nacos 多环境 | `application.yml` 直配本机 |
| Nacos Namespace/Group/敏感配置分组 | 直配 |
| gateway 限流/Sentinel/Swagger 聚合 | 不要 |
| `manager` 跨域层 | 服务简单可省 |
| ES 启动时自动建索引脚本 | 启动时 `if (!exists) create` 即可 |

## 8. 后续要扩展时再补的东西

如果将来从 demo 升级为正式项目，**按这个顺序逐步加**：

1. 拆 `common-*`（7 个模块）
2. 抽 `api-*` 聚合模块
3. 引入 `bootstrap.yml` + Nacos 集中配置
4. 加 `deploy/docker-compose.yml`
5. 加网关限流 + 异常处理
6. 引入 Sleuth/Zipkin
7. 引入 xxl-job 做定时任务
